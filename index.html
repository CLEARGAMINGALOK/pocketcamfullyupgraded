Use USB tethering instead of Wi-Fi
  1. Connect your phone to the computer with a data-capable USB cable.
  2. Enable USB tethering in the phone's network settings, if supported.
  3. Open PocketCam on both devices, sign into the same account, and select sender/receiver. Discovery remains automatic.

USB tethering provides a network route; the actual video still uses browser WebRTC. If your phone exposes a standard UVC webcam to the computer, it may also appear in the Camera Device list. A website cannot register itself as a native USB webcam for every desktop app; that requires a native companion app or virtual-camera driver.

Privacy: only authenticated sessions for the same account can join its private signaling channel. Video/audio are sent over WebRTC peer-to-peer when the network permits; a TURN relay may be needed on some networks. Never share your password.

Made for simple setups

A small studio, without extra clutter.

PocketCam is a browser-based camera-sharing demo built around a lightweight static frontend and WebRTC media.

01 / CAPTURE

Use a supported camera

Choose the front, rear, or an available camera device, then request a preferred resolution. The browser asks for camera and microphone permission.

02 / CONNECT

Pair two browsers

Authenticated device presence discovers sessions on the same account. Supabase Realtime carries private WebRTC signaling; the media itself is sent through WebRTC.

03 / MONITOR

See the stream status

The studio reports whether a stream arrived and shows available video dimensions and indicative connection stats when supported.

What this version does not do: it does not create a native system-wide webcam or microphone for every desktop app. Use the viewer page as an OBS Browser Source where suitable. Zoom, Discord, and similar apps may require a virtual camera or audio-routing tool. Bluetooth is not used for the media stream.
Production note: secure accounts, multi-device history, hardened room access, and dependable connectivity through restrictive NATs need external services. GitHub Pages can host this frontend, but it is not a database or authentication server.
